# Smart Detoxer

Smart Detoxer is a web-based digital wellness and smartphone usage assessment platform designed to help users understand their smartphone dependency and digital habits. The application provides a structured and interactive way for users to evaluate their smartphone usage based on their daily activities, behavioral patterns, and responses to a series of carefully designed questions.

The application includes a secure login system that allows users to access their personal assessment. After logging in, users can complete a questionnaire covering different aspects of smartphone usage, such as how frequently they unlock or check their smartphone, the amount of time they spend using it, usage patterns throughout the day, and other dependency-related behaviors.

After the questionnaire is completed, Smart Detoxer processes the user's responses and assigns points based on predefined criteria. These points are used to generate an overall Smartphone Addiction Score, providing users with an indication of their level of smartphone dependency. The results are presented through a clean and intuitive user interface, allowing users to easily understand their assessment and become more aware of their digital habits.

The project also includes a dedicated Admin Panel for managing application data and users. Administrators can monitor registered users, review assessment-related information, and manage relevant system data through a centralized dashboard.

Smart Detoxer focuses on combining a modern user interface with practical functionality, including user authentication, questionnaire management, scoring logic, data storage, and administrative controls. The project demonstrates the integration of frontend development, backend functionality, database management, authentication, and data analysis into a complete web application.

### Key Features

* User registration and secure login
* Interactive smartphone usage questionnaire
* Point-based assessment system
* Automated smartphone dependency score
* Personalized assessment results
* User data management
* Dedicated admin panel
* Modern and responsive user interface
* Backend and database integration
* Structured data collection and analysis

The primary objective of Smart Detoxer is to promote awareness of smartphone usage patterns by providing users with a simple, interactive, and data-driven way to evaluate their digital habits.
